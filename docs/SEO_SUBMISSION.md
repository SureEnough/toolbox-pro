# 搜索引擎提交指南

## Google Search Console（免费，不需要自定义域名）

1. 打开 https://search.google.com/search-console
2. 使用 Google 账号登录
3. 添加属性 → 选择「URL 前缀」
4. 输入：`https://toolbox-pro-4lq.pages.dev`
5. 验证方式选择「HTML 标记」
6. 复制验证码（格式：`google-site-verification=XXXXXXXX`）
7. 告诉我验证码，我添加到 index.html

### 提交 Sitemap

验证成功后：
1. Search Console → 左侧菜单 → Sitemaps
2. 输入：`sitemap.xml`
3. 点击提交

## Bing Webmaster Tools

1. 打开 https://www.bing.com/webmasters
2. 添加站点：`https://toolbox-pro-4lq.pages.dev`
3. 验证方式同 Google
4. 提交 sitemap：`https://toolbox-pro-4lq.pages.dev/sitemap.xml`

## 百度站长

1. 打开 https://ziyuan.baidu.com
2. 添加站点：`https://toolbox-pro-4lq.pages.dev`
3. 验证站点
4. 提交 sitemap

## AdSense 申请（可尝试 .pages.dev）

1. 打开 https://www.google.com/adsense/start/
2. 输入：`https://toolbox-pro-4lq.pages.dev`
3. 等待审核（1-14 天）
4. 如被拒（域名问题），购买自定义域名后重新申请

## 免费域名选项
